Tentang Aplikasi

Aplikasi ini merupakan media bantu membaca Al-Ma'tsurat Hasan Al-Banna. Aplikasi dibuat sebagai website statis sehingga dapat dihosting secara gratis melalui GitHub Pages.

Tidak ada login, registrasi, maupun database pengguna. Preferensi seperti mode gelap, ukuran font, bacaan terakhir, dan counter hanya disimpan secara lokal pada browser masing-masing pengguna.

Catatan Konten

Data bacaan pada paket ini sudah dirapikan dalam format JSON agar lebih mudah ditampilkan. Sebelum digunakan secara luas, teks Arab, terjemahan, urutan bacaan, dan jumlah pengulangan tetap perlu diverifikasi terhadap rujukan Al-Ma'tsurat Hasan Al-Banna atau sumber resmi yang Bapak gunakan.

Hak Cipta dan Atribusi

Hindari menyalin source code, desain, aset, atau terjemahan dari website lain tanpa izin. Gunakan data yang telah diverifikasi dan cantumkan rujukan pada setiap item bacaan melalui field sumber.
